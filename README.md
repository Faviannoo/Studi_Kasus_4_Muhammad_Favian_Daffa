Penjelasan kode :<br>

1. Membuat Dictionary<br>
<img width="299" height="244" alt="image" src="https://github.com/user-attachments/assets/4bf231ab-cee1-4539-83fe-b726399a0b75" />

Bagian pertama digunakan untuk membuat dan menyimpan data buku. Data disimpan dalam bentuk dictionary bertingkat (nested dictionary). Terdapat tiga data buku, dan masing-masing buku memiliki informasi berupa judul, penulis, dan tahun terbit<br>
<br>

2. Membuat Perulangan dan Menu Utama
<img width="281" height="170" alt="image" src="https://github.com/user-attachments/assets/de9bebd3-9a5c-4d4d-96e9-e36c4854f21c" />

Bagian kedua digunakan untuk membuat menu utama program. Program menggunakan while True agar menu terus ditampilkan dan pengguna dapat melakukan beberapa operasi tanpa menjalankan program kembali<br>
<br>

3. Menampilkan Data Buku
<img width="458" height="329" alt="Screenshot 2026-09-15 205916" src="https://github.com/user-attachments/assets/02e9d448-d7b9-42dc-b523-044e79fd4eff" />

Bagian ketiga merupakan menu Tampilkan Buku. Menu ini digunakan untuk melihat seluruh informasi buku yang tersimpan. Kode tersebut mengambil data berdasarkan key yang ada di dalam dictionary<br>
<br>

4. Menambahkan Data Penerbit
<img width="385" height="372" alt="image" src="https://github.com/user-attachments/assets/906bc721-432b-4c83-8d69-80e4d8fbda8f" />

Bagian keempat digunakan untuk menambahkan penerbit pada buku yang dipilih pengguna. Pengguna terlebih dahulu memilih buku, kemudian memasukkan nama penerbit.

5. Mengubah Data Penulis
<img width="383" height="374" alt="Screenshot 2026-09-15 210922" src="https://github.com/user-attachments/assets/1f0f6b86-c77b-4031-825a-0adfc52d97da" />

Bagian kelima digunakan untuk mengubah nama penulis dari buku yang dipilih. Berbeda dengan menambahkan penerbit, pada bagian ini key "penulis" sudah tersedia. Program hanya mengganti nilai lama dengan nilai baru<br>
<br>

6. Menghapus Data Penerbit
<img width="411" height="459" alt="Screenshot 2026-09-15 210934" src="https://github.com/user-attachments/assets/7f8d6d68-104d-4608-b4e5-fd3e85ce6696" />

Bagian keenam digunakan untuk menghapus penerbit dari buku yang dipilih. Sebelum menghapus data program mengecek apakah key "penerbit" memang ada?, jika belum ada program menampilkan "Data Penerbit Belum Ada".<br>
<br>

7. Keluar Dari Program
<img width="420" height="43" alt="Screenshot 2026-09-15 210943" src="https://github.com/user-attachments/assets/cf13e172-c455-4c4d-a4d2-a664c357eeea" />

Bagian ini digunakan ketika pengguna memilih menu 5. Program akan menampilkan pesan dan menghentikan perulangan menggunakan break. Perintah break berfungsi untuk menghentikan while True, sehingga program tidak menampilkan menu lagi dan selesai dijalankan<br>
<br>

8. Validasi Pilihan Menu
<img width="403" height="41" alt="Screenshot 2026-09-15 210950" src="https://github.com/user-attachments/assets/3314bbef-072c-4fdc-a5d6-dfbcbd60f8f8" />

Bagian ini digunakan untuk menangani pilihan menu yang tidak sesuai dengan pilihan 1 sampai 5. Jika pengguna memasukkan pilihan yang tidak valid, program akan menampilkan pesan peringatan dan kembali menampilkan menu utama<br>
